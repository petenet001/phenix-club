PHENIX CLUB MANAGER - COMPTES DE TEST ET DEMARRAGE
====================================================
Etat au 05/11/2026 (base locale phenix_club). Comptes de demonstration uniquement :
a ne jamais utiliser en production.


1. DEMARRER LES SERVEURS
------------------------

Prerequis : PostgreSQL demarre (brew services start postgresql@18 si besoin).

Terminal 1 - API Laravel :
    cd ~/Projects/web/phenix/backend
    php artisan serve                      # http://localhost:8000 (web + simulateur iOS)
    php artisan serve --host 0.0.0.0       # a la place, pour tester sur un vrai telephone (meme Wi-Fi)

Terminal 2 - Application web (bureau) :
    cd ~/Projects/web/phenix/frontend
    npm run dev                            # http://localhost:5173

Terminal 3 - Application mobile (Flutter) :
    cd ~/Projects/web/phenix/mobile
    flutter run                            # simulateur iOS (API sur localhost:8000)
    flutter run --dart-define=API_URL=http://192.168.79.178:8000/api
                                           # vrai telephone : remplacer par l'IP actuelle du Mac
                                           # (obtenue avec : ipconfig getifaddr en0)

Verification rapide :
    curl http://localhost:8000/up          # doit repondre 200

    puis scanner le QR avec l'application mobile.
  - Code d'acces mobile d'un adherent : fiche adherent > carte "Application mobile"
    > "Activer l'acces" ou "Nouveau code" (code a 6 chiffres affiche une seule fois).
  - Encaissement et recu : fiche adherent > "Encaisser" (le recu s'ouvre ensuite).

4. REMETTRE LES DONNEES DE DEMONSTRATION A ZERO
-----------------------------------------------

ATTENTION : efface toute la base locale (y compris les adherents, paiements et pointages
saisis pendant vos tests) et recree les comptes ci-dessus avec le code 123456.

    cd ~/Projects/web/phenix/backend
    php artisan migrate:fresh --seed

Les dates de demonstration sont relatives au jour du remplissage : refaire cette commande
apres quelques jours pour retrouver les cas de retard, de tolerance et d'absence.
